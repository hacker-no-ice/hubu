# Publication privacy and IP decision

Decision date: 2026-08-13 (America/Los_Angeles)

This record documents the repository owner's decision for publishing Hubu's
current repository and reachable Git history. It is a publication decision, not
a claim that Git presentation tools remove data from existing objects.

## Accepted public material

The owner accepts publication of:

- the personal Outlook commit-email address already present in historical Git
  metadata (the address is intentionally not repeated here);
- Gongbu carry-forward planning and roadmap material, including the intent to
  make Gongbu public soon; and
- abandoned provider and prototype history, including related design and
  discussion context.

The owner attests that Hubu's code and documentation were created with the
right to publish and contain no previous-employer or employer-confidential
material.

## History decision

No history rewrite is requested or required. The historical email exposure is
accepted, and the owner identified no credential or intellectual-property issue
that requires remediation. Rewriting history would therefore disrupt existing
commit identities, tags, and releases without a corresponding security or
privacy benefit.

A `.mailmap` can change how Git displays author or committer identities, and a
changed local Git configuration can affect future commits. Neither removes an
address from existing raw Git objects. Accordingly, this decision requires no
history rewrite, tag replacement, release replacement, or credential rotation.

## Forward-looking practice

Future Hubu commits should use the owner's GitHub-provided noreply commit
address. This reduces new personal-email disclosure without altering existing
history. Repository or account setting changes remain separate administrative
work and are not performed by this decision record.
