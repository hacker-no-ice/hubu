# Release tech specs

Each spec records the technical decisions for one release: interfaces, data
formats, route classes, migrations and known limits. The release design doc
says what the release must achieve and why; the spec says how. Linear issues
link to the spec section they implement. Where an issue and its spec disagree,
the spec wins and the issue is updated.
