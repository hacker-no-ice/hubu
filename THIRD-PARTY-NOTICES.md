Hubu binaries include third-party Rust crates recorded in `Cargo.lock`. Their
license identifiers are preserved in each crate's package metadata and their
license texts are available from the corresponding source distributions on
[crates.io](https://crates.io/).

Hubu is built with the `rusqlite` `bundled` feature. The resulting binaries
include SQLite, which its authors have dedicated to the public domain. See the
[SQLite copyright notice](https://www.sqlite.org/copyright.html).

The Rust dependencies in the current locked release graph use permissive
licenses, including MIT, Apache-2.0, BSD-2-Clause, BSL-1.0, Unicode-3.0,
Unlicense, LGPL-2.1-or-later, and Apache-2.0 WITH LLVM-exception. Some packages
offer more than one license choice. `Cargo.lock` is the authoritative version
inventory for a particular Hubu source revision.
