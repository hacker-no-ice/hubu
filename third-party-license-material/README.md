# Third-party license material

These files preserve repository-level license inputs that are referenced by,
but omitted from, the corresponding crates.io archives. The license generator
matches exact locked package versions so dependency updates fail closed until
their inputs are reviewed again.

- `objc2-0.3.2-LICENSE.md`: `madsmtm/objc2` commit
  `7b1abfd750a2cacaea71d6a56ecfb83cb7de560b`.
- `pbjson-0.9.0-LICENSE`: `influxdata/pbjson` commit
  `48ee5989564e0ace82ad71b87736d3d1b2e0e1cd`.
- `tonic-0.14.6-LICENSE`: `hyperium/tonic` commit
  `6cb6056b5a748bc5a29bd48f4602dbc4e552bb7d`.

`prost-wkt` 0.7.1 and `prost-wkt-types` 0.7.1 reference the standard Apache
2.0 text, so the generator reuses Hubu's identical `LICENSE-APACHE` file.
