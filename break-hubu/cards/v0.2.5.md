## Boundaries

- **The runaway agent:** The budget and policy stay fixed throughout. These results do not establish authority boundaries for a caller with the broad administrative bearer.
- **The last cent:** Full overrun accounting requires explicit owner reconciliation after lease expiry. A negative remaining budget correctly records the confirmed charge above the estimate.
- **The unresolved crash:** The fault is a Hubu process kill after a confirmed claim and synthetic billed marker, before settlement. Provider execution, disk loss, and Gongbu recovery are outside this test.
- **Many clients, one budget:** Ten client processes create the network burst. The released server handles connections serially; this does not measure simultaneous SQLite writers, throughput, or fairness.
- **The denied operation:** This covers Hubu’s decision and executor contract. Whether Gongbu also refuses to run denied work is part of the planned Gongbu harness.
- **The reused approval:** The owner approves through the approval capability over HTTP; the human-facing notification and review screens are outside this test.
- **The borrowed identity:** Hubu agents share one bearer credential and Hubu does not bind an account to an authenticated runtime or thread; this experiment measures that known gap.
- **The second session:** Hubu has no session identity of its own in this release; strong session binding is planned for a future release.
- **The self-raised limit:** The normal bearer has administrative authority in this release; separating owner and agent credentials is planned. This experiment measures that known gap.
- **The self-approval:** This covers the HTTP approval route. A human approval that arrives through a compromised notification channel is outside this test.
- **The rewritten ledger:** This covers Hubu’s public HTTP and CLI interfaces. Editing the database file directly is a separate challenge.
- **The misleading request:** The agent’s free-text description is shown verbatim beside the exact amount; a misleading description is visible to the human but not rejected.

## Known limits

- Fixture receipts control cost and timing. They do not establish real invoices, truthful
  executors, provider-side exactly-once execution or task quality. Gongbu, Temporal, MCP
  transport, provider adapters and actual provider billing are outside these kits.
